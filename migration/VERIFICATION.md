# 第一阶段验证记录

记录日期：2026-09-09。范围为旧内容兼容与基础静态阅读，不包括三维集成或线上切换。

## 检查命令

在 `site/` 执行：

- `npm run check:baseline`：110 个原有内容、附件、静态资源、模板及关键配置的字节保护。
- `npm test`：两种元数据、时区、非法字段、现有语料、新文章、草稿/未来文章、附件过滤和锚点别名。
- `npm run check`：Astro 与 TypeScript 检查，包括应用、验证脚本和浏览器用例。
- `npm run build`：无 Hugo、无主题子模块的静态构建。
- `npm run check:output`：全部文章路径、标题、正文、代码块、原附件字节、内部链接及旧锚点。
- `npm run check:upstream`：已复制字体与其来源记录一致。
- `npm run test:browser`：桌面/手机尺寸 Chromium 的交互与阅读回归。

输出报告写入未提交的 `site/.cache/output-report.json`，失败截图/跟踪写入 `site/test-results/`。CI 保存这些报告及构建产物，不发布。

## 兼容性决策

1. `#main` 是旧 Android 项目文章的真实章节 ID，页面容器改用 `#page-main`，不改文章。
2. 本地既有 Hugo 输出包含 256 个锚点，其中 Linux 调参文章的六个小节在当前 Markdown 已删除。这不是新渲染器丢失正文；通过显式映射保留旧链接，落到仍存在的父章节。映射有独立理由和测试，不恢复过期正文。
3. 代码校验使用独立 Markdown AST 解析器识别嵌套列表里的代码块，而非只识别行首围栏的正则。
4. 文章目录中的 25 个附件保留原 URL 和完整字节；正文中图片采用透传服务，GIF 不转成静态首帧。
5. 明确使用 Asia/Shanghai 解释无时区日期；测试覆盖 UTC、洛杉矶与上海运行环境。

## 验收范围限制

- 当前页面外观是第一阶段基础阅读排版，不是最终三维首页或用户已确认的阅读设计。
- 浏览器手机尺寸模拟不等于 Safari / 真机 iPhone 性能或触摸验证。
- 只检查本地资源和文章互链，不宣称所有外部网站仍可访问。
- 未执行 Hugo 构建；旧锚点来源为已有本地输出，不作为线上状态的证据。
- 普通索引搜索只覆盖标题、摘要与标签，尚非全文搜索。
- 不具备生产发布条件；正式发布前还需阶段二到四的验收。
